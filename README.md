Project Description

StudyForge is a student-focused academic and exam preparation web application designed to make studying more organized, interactive, and effective.

I developed StudyForge as a 19-year-old BCA student to solve a common problem faced by students: having study material but not having an effective way to practice it, identify weak areas, and track improvement.

The platform allows students to import their study notes, text, Markdown files, and PDF material and turn that material into an interactive practice session. StudyForge generates questions based on different levels of Bloom’s Taxonomy, including Recall, Application, and Code Tracing, helping students practice both theoretical knowledge and programming concepts.

Main Functions
📚 Study Material Import — Students can add notes and learning material.
📄 PDF & Text Support — Import study content from PDF and text files.
🧠 Bloom’s Taxonomy Questions — Practice Recall, Application, and Code Trace questions.
⏱️ Timed Quizzes — Students can attempt quizzes with a live countdown.
⚡ Instant Feedback — Answers are evaluated immediately.
📊 Performance Analysis — Students can see their score and performance in different question categories.
💪 Strength & Weakness Identification — The results help students understand which areas need more revision.
🏆 XP & Achievements — Students earn XP and unlock milestones as they practice.
📈 Study History — Previous quiz sessions and scores are stored for tracking progress.
📝 Downloadable Reports — Students can save a session report for later review.
🔐 Authentication — Secure student login and account creation using Supabase Authentication.
📱 Responsive Design — Designed to work on both mobile phones and computers.
🎓 Student-Oriented Interface — The interface is designed specifically around focused academic study rather than a generic AI dashboard.

🔒 Security
Authentication is handled through Supabase.
Frontend applications must use only public/publishable credentials.
Private keys and service-role credentials must never be committed to GitHub.
Email confirmation helps verify newly registered accounts.
